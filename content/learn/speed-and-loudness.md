# Speed, loudness and file formats

## Speed
Set speed from **0.7 (slow)** to **1.3 (fast)**. 1.0 is natural.
- Reels and Shorts: 1.05–1.15 keeps energy up.
- Tutorials and courses: 0.95–1.0 is easier to follow.
- Changing speed does not change the pitch.

## Loudness
Every file is levelled to a consistent loudness so it doesn't sound quiet next to other videos.
- **Default: -14 LUFS**, the loudness most short-video platforms and YouTube target.
- **-16 LUFS** is common for podcasts and long YouTube videos.
- Peaks are kept below **-1 dBTP** (true peak), so the audio won't distort after upload.
- You can switch loudness levelling off in Advanced options if you want to master the audio yourself.

**Tip:** if you add background music in your editor, keep the music about 15–20 dB quieter than the voice, or use your editor's "ducking" feature.

## Clean edges and pauses
- Silence at the start and end is trimmed to about 0.1 seconds, so the voice starts right away.
- Between sentences: a 0.25 s pause. Between paragraphs: a 0.6 s pause.

## MP3 or WAV?
| | MP3 | WAV |
|---|---|---|
| Quality | 192 kbps, 48 kHz | Lossless, 16-bit, 48 kHz |
| File size | small (~1.4 MB per minute) | large (~5.6 MB per minute) |
| Best for | phones, CapCut, Instagram, quick edits | Premiere, DaVinci, professional mixing |

Both are 48 kHz, the standard for video, so they line up perfectly with your timeline.
